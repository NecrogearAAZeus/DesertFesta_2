# 게임안 — 빼빼로 구슬 경마 (가제)

> 작성: 2026-11-06 / 상태: **⏸ 보류** — 혼자 하기엔 공수가 큼. 공동 개발자가 붙으면 재개.
> 참고: lazygyu 마블 룰렛 (https://lazygyu.github.io/roulette/, MIT. "마블 룰렛" 명칭은 상표 출원 중이라 사용 금지)

---

## 1. 한 줄 룰
"어느 빼빼로 구슬이 1등할지 사탕을 걸어라."

## 2. 확정
| 항목 | 결정 |
|---|---|
| 구슬 | **빼빼로 구슬 4~6개에 베팅** (참가자 1명당 구슬 1개 방식은 기각) |
| 물리 | **matter.js** — 서버에서만 실행 (브라우저에는 안 들어감). npm 추가 승인 대기 |
| 시각 | 구슬이 장애물 맵을 굴러 내려가는 낙하 경주 |
| 경주 시간 | **최소 1분** (목표 55~75초) |
| 동기화 | 서버가 경주를 1회 계산 → 구슬 위치 녹화 → 전원 같은 녹화 재생 |

## 3. 한 판 흐름
```
[베팅 30초]  빼빼로 1개 선택 + 걸 사탕 입력 (마감 전 변경 가능)
   ↓ 운영자 "마감"
[경주 ~60초] 서버 계산 결과를 전원 화면에서 재생 (카메라 + 미니맵)
   ↓
[결과 10초]  1등 공개 → 배당 정산 → 이번 판 획득 순위
```
한 판 약 2분, 20분이면 약 10판.

## 4. 배당 (Twitch 예측 방식)
```
배당 = 전체 판돈 ÷ 우승 빼빼로에 걸린 판돈
받는 사탕 = 내가 건 사탕 × 배당
```

## 5. 맵
- **세로로 긴 맵**: 폭 = 화면 1개, 높이 = 화면 6~8개
- 장애물 (모두 쉬움)

| 장애물 | 구현 | 메모 |
|---|---|---|
| 핀 | 고정 원 + 탄성 | |
| 좁은 입구 | 고정 벽 2개로 깔때기 | 폭 ≥ 구슬 지름 × 2 |
| 가속·감속 패널 | 센서 영역(충돌 없음) 안에서 매 프레임 속도 × 계수 | |
| 경사로 | 기울어진 고정 막대 | |

- **맵 제작 방식 (추천: ①)**

| | 방식 | 공수 |
|---|---|---|
| ① | **구간 블록 쌓기** — `pins / zigzag / funnel / boost / slow` 블록을 위→아래 목록으로 | 기본 포함 |
| ② | Tiled 에디터로 그려서 JSON 내보내기 | +0.3일 |
| ③ | 자체 맵 에디터 | +1일 (비추천) |

```js
// games/race-map.js (①의 모습)
module.exports = [
  start(),
  pins({ rows: 6 }),
  zigzag({ turns: 3 }),
  funnel({ gap: 60 }),
  boost({ factor: 1.3 }),
  pins({ rows: 8 }),
  slow({ factor: 0.7 }),
  zigzag({ turns: 4 }),
  finish(),
];
```
- **미리보기 페이지**: 맵 수정 → 서버 재시작 → 미리보기에서 바로 경주 재생 (맵 다듬기 반복용)

## 6. 카메라 (브라우저 전용, 물리와 무관)
- 선두 구슬을 부드럽게 따라감 (추천) / 또는 내가 건 빼빼로를 따라감
- 옆에 **미니맵**: 맵 전체를 세로 막대로 줄이고 구슬 위치를 점으로

## 7. 안전장치
- 3초 이상 멈춘 구슬은 살짝 밀어줌 (끼임 방지)
- 90초 지나면 강제 종료, 미도착 구슬은 진행 거리로 순위

## 8. 공수 (추정)
| 부분 | 공수 |
|---|---|
| 물리 + 녹화 | 0.3일 |
| 맵 블록 + 미리보기 | 0.3일 |
| 렌더러 + 카메라 + 미니맵 | 0.4일 |
| 베팅·배당 화면 | 0.3일 |
| 밸런스 시뮬 (빼빼로별 우승 확률 비슷 / 완주 55~75초) | 0.2일 |
| **합계** | **약 1.5일** |
