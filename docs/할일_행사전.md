## 동료 개발자 합류
- `.env`는 내 키를 그대로 주지 않는다. Console에서 **친구용 API 키를 따로** 만들어 개인 메시지로 전달 → 행사 후 삭제
- `ADMIN_PASSWORD`는 친구가 자기 PC에서 아무 값이나
- Node 24 필수 (`node:sqlite`). `npm install` 한 번이면 됨 (`ws` 등 추가 설치 불필요)
- 동시 요청 25건 한도는 조직 전체 공유 → 행사 중엔 같은 조직 키로 테스트 금지
