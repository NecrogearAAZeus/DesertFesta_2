# 게임안 A — 사탕 쟁탈전 (공격·방어)

> 작성: 2026-11-06 / 상태: **❌ 드롭 (2026-11-06)**
> 드롭 사유: 재미는 있을 것 같으나 논의할수록 룰이 복잡해짐. "룰은 매우 간단해야 한다" 대원칙과 충돌.
> 아래는 드롭 시점까지 정리된 최종 형태 (다음 행사·재검토용 기록).

---

## 1. 한 줄 룰
"매 라운드 채집·공격·방어 중 하나를 몰래 고른다. 셋은 가위바위보 관계다. 마지막에 사탕 제일 많은 사람이 1등."

## 2. 구조
- **라운드제**. 낮/밤 같은 턴 구분 없음. 한 라운드 = 선택 1번 + 동시 공개.
- **탈락 없음**. 사탕 0개여도 계속 참여.

### 2-1. 행동 3개 (가위바위보)
```
채집 → 방어를 이김  (방어한 사람은 수입 0, 채집한 사람은 +N)
방어 → 공격을 이김  (나를 공격한 사람의 사탕을 역으로 뺏음)
공격 → 채집을 이김  (채집하던 사람의 사탕 X%를 뺏음)
```
- 방어 비용 = **그 라운드 수입 0** (% 소모 대신. 계산 불필요)
- 공격끼리 맞붙으면: "대상이 방어가 아니면 공격 성공" (미확정)

### 2-2. 공격 대상 선택 UI
- 공격 버튼 → 전체 참가자 목록 표시, **사탕 많은 순 → 적은 순** 정렬
- 목록에서 아이디(캐릭명) 클릭으로 지목
- 대상 제한 없음 (상위 N명 제한 안 함)

## 3. Cash 'n Guns에서 가져온 것 / 버린 것
| 요소 | 판단 | 이유 |
|---|---|---|
| 총알 3발 제한 | 버림 | 25명 이상이면 남의 총알 수를 아무도 안 셈 |
| 부상·탈락 | 버림 | 탈락 후 대기 = 심심함 |
| 대부(총구 돌리기) | 버림 | 룰만 늘어남 |
| 동시 비밀 선택 → 한꺼번에 공개 | 남김 | 대규모 인원에도 대기 없음 |
| 엎드리기 = 안전하지만 수입 0 | 남김 | 방어 비용의 가장 단순한 형태 |
| 수확+습격 한 턴 통합 | 남김 | 룰 단축 |

## 4. 미결 (드롭으로 중단)
- 뺏는 비율 X%: 크면 운 게임, 작으면 역전 안 됨 → 시뮬 필요했음
- 공격끼리 맞붙을 때 처리
- 여러 명이 한 명 공격 시 분배

## 5. 컨셉 입히기 (안)
- 채집 = 빼빼로 굽기 / 공격 = 빼빼로 가로채기 / 방어 = 빼빼로 상자 잠그기

## 6. 리스크 (드롭 사유 포함)
- 행동 3개 자체는 단순하지만 예외 규칙(맞공격, 다수 공격, 비율)이 계속 붙음
- 숫자 밸런스를 감으로 정해야 함

### 7-3. 초안에 바로 붙일 후보
- **수확 턴 = 풍요와 기근**: "많은 쪽 vs 적은 쪽, 고른 인원끼리 나눔, 과밀이면 0"
- **습격 턴 = 비공개 동시 공격·방어** (먹이사슬 역공, Cash 'n Guns 지목)
- **방어 헛방 페널티**: 방어했는데 아무도 공격 안 오면 다음 수확 감소 → 결정 항목 3번
- **몰리면 나눠 먹기**: 여러 명이 한 명 공격하면 뺏은 양을 공격자 수로 나눔. 방어에 성공하면 공격자 전원에게서 역탈취 → 결정 항목 4번
- **강공격 횟수 제한**: 비율 강탈 공격을 게임당 2~3회로 (설계 제안, 원작 사례 아님) → 결정 항목 1번
- **역전 이벤트**: 마지막 턴에 "꼴찌가 1등에게서 N개" 등을 운영자 버튼으로 (만칼라·Chance Time)
