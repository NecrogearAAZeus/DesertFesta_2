# 구슬 경마 트랙·연출 개편 — 2026-11-07

현재 채팅에서 전달받은 기획을 기준으로 작성했다. 과거 베팅형 경마 문서와는 다른, 참가자마다 구슬 한 개를 배정하는 60초 관전 게임이다.

추가 수정: 조디아크를 58%로 이동하고 미완주 구슬 전체의 앞뒤 반전·공중 회전·착지를 추가했다. 버섯 발동마다 사용자 제공 티모 이미지 두 장을 번갈아 표시한다. **이번 추가 수정은 사용자 요청에 따라 테스트를 실행하지 않았다. 아래 시간 측정표는 추가 수정 전 버전의 기록이다.**

## 조사와 적용

- [마블 룰렛 맵 소스](https://github.com/lazygyu/roulette/blob/main/src/data/maps.ts): 꺾인 벽과 좁은 출구, 엇갈린 장애물, 서로 다른 방향으로 도는 회전봉을 확인했다. 좁은 폭만 지정하는 대신 구슬이 실제로 부딪히는 핀·깔때기·경사판·회전봉을 직접 배치했다. 외부 맵 좌표나 소스를 복제하지 않았다.
- [마블 룰렛 물리 소스](https://github.com/lazygyu/roulette/blob/main/src/physics-box2d.ts): 정적 충돌체와 움직이는 충돌체를 구분한다. 이번 게임은 별도 패키지 없이 원과 캡슐의 접촉 및 회전봉 표면 속도를 처리한다.
- [마블 룰렛 구슬 소스](https://github.com/lazygyu/roulette/blob/main/src/marble.ts): 끼인 구슬을 감지해 밀어주는 복구를 참고했다. 여기서는 1.5초간 전진하지 못할 때 좌우 충격을 주며 위치를 순간이동시키지 않는다.
- [Riot: Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/): 시각적 범위와 피격 판정의 일치, 중요한 공격에 더 큰 시각적 비중을 주는 원칙을 적용했다. 보스는 예고→발동→잔향 단계로 표현하며 작은 장애물 충돌은 짧은 스파크로 제한했다.

## 코스·물리

- 기존 기본 시드의 첫 완주: 트랙 1 12.82초, 트랙 2 11.37초, 트랙 3 12.43초. 이전 물리 함수를 그대로 60초까지 실행해 측정했다.
- 실제 파일은 `track1.jpg`가 세로 협곡, `track2.jpg`가 루프, `track3.jpg`가 U자다. 메뉴의 코스타/U자=track3, 림사/루프=track2, 골드 소서/세로=track1로 연결하고 이미지의 길을 따라 경로를 다시 지정했다.
- 세 코스의 길이는 각각 18,000 월드 단위다. 완주율을 높여 달라는 추가 요청으로 전진 속도 상한을 초당 350→380, 중력 가속도를 1900→2050으로 올렸다. 출발 위치는 거리 0 이하이고 충돌에 따른 위치 보정까지 전진 상한에 포함된다. 방해가 전혀 없을 때 거리/최고 속도는 약 47.37초로, 이전의 51.43초 하한은 더 이상 적용되지 않는다. 실제 완주 시간과 완주율은 이번 변경 후 측정하지 않았다. 결승선을 시간으로 잠그지는 않는다.
- 물리 좌표는 코스 거리 s와 좌우 위치 u다. 이미지의 곡선 위로 투영하므로 루프가 가까이 지나가더라도 다른 구간으로 건너뛰지 않는다. 일반적인 자유 공간 2D 강체 엔진과는 다른 코스 전용 근사 모델이다.
- 고정 120Hz, 접촉 해결 3회, 핀 숲(12%), 깔때기(24.5%), 교차 경사판(49%), 회전봉(59%·81%). 구슬 간 충돌과 실제 장애물 접촉으로 병목과 순위 변경이 발생한다.
- 물리 시드와 효과 렌더링은 분리했다. 렌더링 빈도는 난수 소비·물리 상태를 변경하지 않는다. 같은 엔진의 동일 시드 결과를 검증했으며 서로 다른 모든 브라우저 엔진에서의 비트 단위 동일성까지 검증한 것은 아니다.

## 효과

- 조디아크: 선두 58%에서 기존 마법진·눈·방향 예고와 구슬 떨림→0.45초 동안 구슬의 전체 회전 경로가 보이도록 카메라 축소→카메라 위치·각도·배율을 고정한 채 구슬만 1초 동안 180도 공중 반전→실제 코스 좌표를 `현재 최저 거리 + 현재 최고 거리 - 기존 거리`로 바꿔 앞뒤 순위를 반전→착지 충격파·구역 내 상위 20명 측면 충격·벽 충돌 스파크. 착지 후 0.18초 유지한 뒤 일반 선두 추적 시점으로 부드럽게 복귀한다. 전용 화면 회전·기울기·흔들림은 없다. 완주자는 이동 대상에서 제외한다. 준비와 회전 중 구슬 물리는 멈추지만 경기 시계는 계속 흐른다.
- 심연: 70%에서 주황 부채꼴 예고가 차오름→회전 화염·충격파→부채꼴에 닿은 구슬을 균열 벽 쪽으로 밀어냄→벽에 부딪힌 뒤 스턴. 그리는 각도와 반경을 판정에도 사용한다.
- 탱크버스터: 붉은 머리 위 표식, 차오르는 범위, 폭발 링·파편·주변 넉백. 저격: 조준선·조준경·탄도·피격 스파크. 바나나: 역방향 점프·그림자 분리. 버섯: 독구름·보라색 입자·부유 궤적.
- 버섯 추가 효과: 기존 트랙 안의 피격 구슬 옆 위치를 유지하며, 티모 이미지 크기는 메인 72px·PIP 40px로 2.6초간 표시한다. 불투명도는 기본 100%로 복원했고 사라질 때만 페이드아웃한다. 두 이미지를 발동 순서대로 번갈아 사용하며 두 번째 이미지의 넓은 여백은 그릴 때만 잘라 캐릭터가 보이게 한다. 파일 자체는 원본 그대로 보관한다. 화면 밖에서 발동한 경우 메인 화면 가장자리로 카드를 옮겨 표시하고, PIP에서는 해당 구슬이 보일 때 작은 카드를 표시한다.
- 화면 흔들림·회전은 줄이기 옵션과 OS의 reduced-motion 설정을 지원한다. 이 설정은 판정과 순위에 영향을 주지 않는다.
- MP3가 없는 경우 자막 폴백을 유지하며 동시에 최대 두 개의 자막만 표시한다.

## 실행과 파일

`npm start` 후 `http://localhost:3000/games/marble-race/index.html`을 열면 임시 경주가 자동 시작한다. 같은 시드를 다시 실행하거나 새 시드, 트랙, 인원, 배수를 선택할 수 있다. 서버 중계는 `?live=1`로 접속한다.

- `track.mjs`: 이미지 경로 곡선·장애물 배치
- `simulation.mjs`: 물리·함정·보스 판정·60초 결과
- `renderer.mjs`: 메인/PIP 카메라·코스·시각 효과
- `game.js`: 브라우저 루프·UI·사운드·SSE
- `config.js`: 이미지/사운드 경로
